# 飞书绑定阻塞任务定位（0.8.8）

提示文案：有调研或上传正在执行，请完成/停止后再重新绑定。

绑定、应用登记、更换应用接口的409响应包含实际阻塞任务的名称、类型、状态和任务ID，按任务去重；只返回展示所需元信息，不包含Prompt、资料正文或凭据。更换应用场景的句尾为“切换飞书应用”。原有阻塞条件保持不变。

弹窗列出阻塞任务，提供“定位卡片”，对已有原生会话的任务提供“打开会话”。定位时关闭弹窗，清除搜索过滤，切换到日报、周报、内部资料或历史AI任务页面，滚动并聚焦卡片，高亮5秒。历史列表未加载到该任务时，按任务ID补取元信息，不创建新任务或会话。

无法确认结束的遗留上传显示“上传待确认”，避免把失败卡片误报为正在调研；排队、调研、等待保存和收尾分别标注。任务处理后可点击原有“重新获取应用绑定二维码”重新检查，无需关闭重开弹窗。不会自动停止任务或绕过绑定保护。

验收覆盖API结构、任务去重与状态分类、敏感数据过滤、全部任务类型的卡片定位与原会话跳转，以及现有连接、通知和目录切换回归。插件由用户手动安装。
