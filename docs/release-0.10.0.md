# 0.10.0 · 专题总报与日报详情页

- 专题卡片进入独立详情页，分别展示专题总报和全部日期的专题日报。
- 配置名称更新为“调研方向”，数据源继续复用全量信息库的选择组件。
- 统一存储结构为“专题调研 / 具体专题 / 总报、日报”。每期日报独立建文档，重试只复用对应日期报告，不再覆盖总报或上一期日报。
- 保留旧版专题报告和会话，支持从新旧目录导入历史文档；目录在服务端保存锁内复用并核对，防止跨专题或跨日期覆盖。
- 原生会话重试同时核对轮次编号，避免毫秒时间相同时将旧轮次误标为完成。
- 保留独立日报设置、北京时间调度、漏发补跑、通知重试及原生会话续聊。

详见 [专题总报与日报说明](topics-0.10.0.md)；PRD 修订版 468，目录名称采用用户明确确认的“专题调研”。

本机验收：373 项业务测试通过、2 项按既有平台条件跳过；48 项浏览器验收通过，新增的轮次边界回归与专题页面验收通过。
