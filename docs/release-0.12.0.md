# 0.12.0 · 资料删除与内部资料状态修复

- 对齐 PRD revision 580：公司资料和内部资料卡片新增删除按钮，核对具体文档后确认移入飞书回收站。
- 公司删除只回收对应文档，清理本地卡片并防止旧索引、旧回执重新显示已删文档；不回收共享目录或公司索引。
- 内部资料回收卡片已关联的逐字稿、会议纪要与平台上传的原始副本；网络原始资料、其他卡片共用的文档及已合并进公司库的信息保留。
- 删除操作按账号及根目录校验，运行中的关联任务须先完成或停止；异步回收可继续核对，失败不冒充成功。
- 专题总报使用“XXX专题调研总报”命名；继续识别旧“总报”，后续更新可原地重命名并复用链接。
- 修复内部资料更新已完成、但回执漏报信息库目录与索引字段时被判失败的问题。仅在原保存锁快照已确认根目录和全部公司文档链接时补齐元信息。
- 旧版同类失败卡片新增“核对已完成结果”：读回逐字稿、会议纪要和公司文档对应引用后恢复完成状态，不重新解析、不追加云端内容、不补发通知。

验收覆盖正常交付、历史状态核对及错误/取消保护、删除确认与续查、网络来源和共用资料保护、旧索引过滤及总报名兼容。
