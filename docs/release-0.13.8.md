# 0.13.8 · 插件更新入口

行研工作台原生面板显示已安装版本、可用版本和更新状态，支持手动检查与安装，并可开启空闲时自动更新。自动检查每 6 小时进行一次；发布满 12 小时、当前没有运行中任务或保存写入时才尝试安装，忙碌时稍后重试。自动更新默认关闭。

更新只接受 GitHub 不可变正式 Release 中带摘要的更新清单。检查到新版后，后台下载完整 TGZ 安装包及当前版本的恢复包，核对 Release 资产的文件名、大小与 SHA-256，以临时文件写入本机数据目录并在校验成功后原子落盘；两份包齐备才显示可安装。重启后复用已校验的缓存，下载失败每 5 分钟重试。发布 CI 继续执行 Windows 与 macOS 的构建、测试、打包和冷安装验收，再生成更新清单。安装由 DSH 插件管理器执行，失败时保留可见的错误状态；无热重载的宿主会提示重启，重启后记录实际加载的版本。仓库必须先启用 GitHub Release immutability，才能向自动更新通道发布新版本。

首次使用此更新链路需安装固定 Git 提交的正式版；从本地 `link:` 安装的开发版不参与自动更新。切换时插件将已校验的本地 TGZ 路径交给 DSH 插件管理器，不再请求 GitHub。有热重载的宿主先移除旧版，再从本地包安装；失败时清理未完成的新版本，并从缓存的旧版包恢复。无热重载的宿主直接安装本地包并提示重启，失败时由 DSH 保留原有配置。安装前重新校验两份缓存包，因此下载完成后可以断网安装或恢复。更新后的本地包仍可继续参与后续自动更新。
