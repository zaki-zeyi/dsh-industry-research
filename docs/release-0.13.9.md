# 0.13.9 · 本地槽位自动更新

本版引入稳定启动层。首次安装本版仍由 DSH 插件管理器完成；之后行研工作台自动更新只下载、校验并解压新版完整包到独立槽位。重启时先加载新版并核对工作台健康状态、版本及数据目录，成功后确认当前槽位；失败时直接启动保留的旧槽位，不下载或重装旧包。

更新清单只接受 GitHub 不可变正式 Release 的 SHA-256 校验资产；下载到临时文件后校验大小和摘要，安装前再次校验缓存包。完整包解压前检查归档路径与文件类型，槽位状态使用原子文件替换。自动更新默认关闭；同一失败版本被隔离，等待下一正式版，避免重启后重复失败。旧槽位不被自动删除。

独立新建文档继续并行；既有公司文档仍按文档排队写入，公司索引在报告和公司正文完成后单独提交。此版本不改变飞书文档写入语义。

稳定启动层以及 DSH 客户端入口本身不通过本链路更新；这类变更需要再次通过 DSH 插件管理器安装新版启动层。自动下载完成后需要重启 DSH 才会切换，重启时应先完成正在执行的任务。
