# v0.8.13

统一 main、默认 release 安装分支及 GitHub 版本包的发布流程，保留 v0.8.12 目录复用修复。

- Windows/macOS 的构建、业务、浏览器及独立安装包验收作为发布前置条件。
- 发布分支使用实际验收的 ZIP 目录，检查版本与 SHA256。
- 裸 GitHub 链接冷缓存安装必须得到当前版本，禁止旧版安装结果被误判通过。
- 标准产物为 ZIP、TGZ、SHA256 及包含源码提交的来源清单。
- 统一桌面与网页版安装说明，区分历史 Windows 一体化 EXE。

真实模型、飞书写入和 macOS 桌面交互不以夹具测试代替。

飞书连接按当前实现验收：应用登记后生成个人授权二维码，用户手动点击“我已授权”；失败后重新获取二维码，账号不匹配继续拒绝绑定。修复轮询恢复后残留错误提示，清理旧状态机测试与过时文档。

本地334项单测、40项浏览器通过；实际包的Node/Electron独立安装、隔离真实DSH工作台原生续聊、并行调研、官方Schedule均完成验证。模型和飞书交付使用本机夹具。
