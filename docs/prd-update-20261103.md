# 最新PRD变更实现记录

来源：https://zcnnosk3k1j9.feishu.cn/wiki/LiujwLZvIirk8akSjyVcr0Axn4g

已通过 `lark-cli` 用户身份读取最新在线文档，当前修订号为 **1172**。完整原文快照见 [`prd-lightweight-1172.md`](prd-lightweight-1172.md)。

- 独立手动生成日报、定时生成日报、手动生成周报、定时生成周报。
- 定时任务复用手动配置表单，分别保存公司、维度、数据源、其他要求和可编辑 Prompt，点击「完成」保存。
- 日报统计前一天 0 点至 24 点；周报「上一周」按北京时间上一个完整自然周（周一至周日）实现。
- 报告按公司/维度保存至对应飞书子目录，同时增量去重写入全量信息库，保留来源、事件发生日和入库日；部分失败标缺口。
- 机器人通知当前任务绑定用户：全部无更新发送「本日/周无更新」，有更新发送飞书报告链接；通知失败可独立重试。
- 默认日报每天09:00、周报每周五09:00，均为北京时间，官方DSH Schedule触发。
- 新增 FR-04 内部资料导入解析：支持本地文件路径或网络链接、视频音轨/录音逐字稿、说话人和时间位置、事实核对、内部资料与原始资料双目录保存，以及完成后的机器人通知。
