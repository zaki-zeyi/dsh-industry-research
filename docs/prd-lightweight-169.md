# 核心功能

## FR-01 全量信息库

### 用户故事

用户集中查看关注的公司的某些维度结构化的资料，并通过AI任务从某些信源补充信息，便于持续开展研究。

### 入口和前置条件

**入口：**【行研工作台】页签的里面的【全量信息库】页签。

### 用户流程与页面交互

| **流程名** | **过程描述** | **业务规则** |
|-|-|-|
| 连接绑定飞书 | 点击【绑定飞书】按钮可以扫二维码完成绑定飞书和授权飞书应用，用于后续进行飞书文档上传，点击【重新绑定】重新绑定飞书账号和飞书应用 | 启动调研前需要求绑定，不需要读取目录列表权限。  <br/>飞书绑定和飞书应用创建和绑定都是用二维码，先绑定飞书账号再绑定应用，如果飞书账号改变，重新绑定新账号的应用 |
| 设置飞书云盘根目录 | 点击【设置飞书根目录】按钮，可以设置【根目录名字】或【飞书文件夹链接】。 | 默认根目录是【行研工作台】目录，如果没有则新建。  <br/>也可以提供目标飞书文件夹链接，Agent 直接往这个文件夹上传报告，不需要读取目录列表。 |
| 查看全量信息库 | 点击【全量信息库】页签，【存储位置】获取并显示全部已收录公司列表。  <br/>点击特定公司卡片跳转到对应的飞书文档。  <br/>点击【刷新】可以更新目前【存储位置】已有的公司列表 | 存储位置：飞书根目录目录的【全量信息库】下  <br/>存储格式：一个文档存储一个公司结构化资料。按照以下维度展示：  <br/>【维度】默认：主营业务及产品、技术路线、产品规划及每代产品核心性能、团队背景及过往经历、融资轮次及估值。  <br/>示例如下：  <br/>“后摩智能  <br/>主营业务及产品：xxxx【信息来源】【日期】  <br/>技术路线：xxxx【信息来源】【日期】”  <br/>每一条资料的具体条目后，紧跟提供【信息来源】链接点击可直接定位到原始来源和具体位置（参考chatgpt调研时在信息后附带链接）。  <br/>冲突处理：如有信息冲突可高亮标记。 |
| 更新全量信息库 | 点击【更新全量信息库】按钮开启弹窗，设置本次【调研公司】、【调研维度】、【数据源】、【其他要求】后，呈现本次ai会话的默认任务prompt。用户也可点击ai会话输入框中直接修改/输入自己的prompt。点击【启动】按钮启动ai任务，呈现ai对话。 | ai任务的默认prompt：“帮我对【调研公司】在【数据源】进行【调研维度】的调研，并满足【其他要求】，自动去重增量保存到飞书云盘【全量信息库】中。并呈现本次更新摘要”。  <br/>【调研公司】默认以下公司：后摩智能、光羽芯辰、微纳核芯、原粒半导体、智辰半导体、九天睿芯、曦选创智、芯动力科技、元涌科技、算苗科技、登临科技、鲲云科技、铭芯启睿、亿铸科技、进迭时空、行云集成、九万里科技。  <br/>【数据源】默认信源：企查查、天眼查、36氪创投平台、投中网、IT桔子、艾瑞咨询、云岫资本公众号，以及芯东西、芯师爷、机器之心、硬AI、智东西、半导体行业观察、甲子光年、铅笔道和内部材料。云岫资本图片识别结果需关联原图片，并继续检索相关报道。可选全网查询。可以增加自定义数据源（增加后下次永久可配）。  <br/>【调研维度】默认基础信息库呈现的【维度】，可以选择和自定义增加维度（增加后下次永久可配）。  <br/>【其他要求】默认无，可以输入自定义其他要求。  <br/>AI会话从dsh映射过来，复用宿主dsh的原生会话。可以前端跟继续跟agent对话。（agent默认打开系统全部权限，默认使用标准模式）。呈现到历史ai任务页面里。  <br/>绑定一个插件级工作区，所有ai会话存储在这个工作区下  <br/>调研超时时间超过30分钟，定义为任务失败 |
| 浏览历史ai任务 | 任务结束后呈现在【历史ai任务】列表中，点击某个【历史ai任务】继续历史ai会话。 | 【历史ai任务】显示完成状态。 |

### 异常与边界

- 系统异常：AI会话或获取失败时显示失败，保留已完成内容与任务记录，允许重试。

### 验收用例

自动生成验收用例，每次新功能开发完成自动新增和运行验收用例，每次错误修复后增加对应错误的用例。每次验收帮我更新dsh插件，验收完成上传github。
