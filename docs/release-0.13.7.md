# 0.13.7 · 插件更新入口

行研工作台原生面板现在显示已安装版本、可用版本和更新状态，支持手动检查与安装，并可开启空闲时自动更新。自动检查每 6 小时进行一次；发布满 12 小时、当前没有运行中任务或保存写入时才尝试安装，忙碌时稍后重试。自动更新默认关闭。

更新只接受 GitHub 不可变正式 Release 中带摘要的更新清单，并将 DSH 的更新目标固定到已通过发布验收的 Git 提交。发布 CI 继续执行 Windows 与 macOS 的构建、测试、打包和冷安装验收，再生成更新清单。安装由 DSH 插件管理器执行，失败时保留可见的错误状态；无热重载的宿主会提示重启，重启后记录实际加载的版本。仓库必须先启用 GitHub Release immutability，才能向自动更新通道发布新版本。

从本地 `link:` 安装的开发版无法使用 DSH 原生 `updateBundle`；首次使用此更新链路需要通过 DSH 插件管理器安装固定提交的正式版。当前插件仅预先下载更新清单，Git 插件包仍由 DSH 在切换过程中下载。该链路尚未实现“完整包先下载并校验、随后离线安装”；有热重载时 DSH 会先移除旧版，安装失败才尝试从旧 Git 地址重装。因此本版本不能把断网后的安装或恢复视为已验证能力。
