# 0.13.0 · 报告删除与 PRD4896

- 补齐友商分析卡片的删除入口；新增日报、周报删除。点击删除先核对具体飞书文档，取消不执行删除，确认后移入回收站。
- 每次只回收选中的报告，保留公司资料、共享报告索引、其他报告和已有定时计划。运行中的关联任务须先完成或停止；没有云端文档的失败记录可仅移除卡片。
- 异步删除保留任务号并支持继续核对；权限、网络或范围校验失败时保留卡片。按账号、应用和根目录校验，不删除其他目录的文档。
- 删除后过滤旧索引、云端缓存、原任务和迟到的刷新结果，阻止通过旧回执、任务重试或通知重试恢复已删报告；继续保留 AI 会话历史。
- 对齐迁移后 PRD 修订版 4896：使用“去重合并”措辞；状态更新保留旧状态、旧时间和来源，新状态同时注明时间及来源，每条条目附来源链接。上一版内置规则原位升级，保留自定义研究要求。

验收覆盖友商分析、日报和周报的删除确认、取消、异步续查、失败保留、目录及账号隔离、旧索引过滤、刷新竞态、公司资料与定时配置保护。
