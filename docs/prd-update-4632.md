# PRD4632：根目录切换与公司卡片同步

2026-11-06 对照在线 PRD revision 4632。相对4549只新增FR01根目录“导入/更新”规则：本地卡片指向的根目录与当前根目录不一致时，更新公司列表和文档链接，使其与当前存储位置一致。

## 修复

- 公司库缓存按应用与实际根目录 token 隔离；同名不同目录互不混入，同一目录改名仍可复用。
- 完整导入后以当前目录快照更新卡片，移走的公司不再显示；同名公司的文档链接以当前目录为准，不由旧文档更新时间决定。
- 新目录为空或没有全量信息库子目录时显示空列表，不回退旧公司目录，也不把根目录杂项当成公司文档。
- 原目录缓存、历史任务及历史文档保留。旧版按名字保存的缓存，只在记录的根目录 token 或唯一历史交付能够证明归属时迁移；无法证明时重新读取当前目录。
- 保存设置及刷新请求的迟到响应不能覆盖新目录卡片；后端检测导入中目标改变并返回409。同步期间刚交付的同目录新公司仍保留。
- 分页截断、文件列表缺失、读取失败不视为空目录，不清除已确认的当前目录缓存。
- 调度记录、内部资料目录记录和写入锁继续使用原来的逻辑命名空间，避免首次创建根目录后 token 确认导致锁键变化或旧记录失联。公司文档本身使用独立的实际根目录缓存。

## 验证

87项相关单元/接口测试通过，包括公司库、导入、友商分析、云端调研、并行保存、日报周报、内部资料、绑定和通知。5项浏览器测试通过，包括根目录切换/空目录/迟到响应的新回归与友商分析、日报周报现有流程。

本机打包为0.8.7，PRD元信息同步为4632。真实飞书目录写入不作为测试夹具验收结果；桌面安装状态单独报告。
