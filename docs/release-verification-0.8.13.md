## 已完成

- 新增统一发布工作流：Windows/macOS 全量验收、打包、独立安装验证通过后，才同步默认 release 安装分支、冷缓存安装公开 GitHub 链接并创建版本 Release。
- 发布前校验源码/产物版本、源码提交和包 SHA256。新增三项拒绝旧版本、篡改包、错误安装目录的测试，连同安装契约共 5/5 通过。
- Windows 本机执行官方 DSH CLI，将实际 0.8.13 安装目录添加到隔离的 local-install Profile；dump-config 确认 bundle 与插件行，未修改 desktop Profile 或真实研究数据。
- 安装包从独立临时目录以离线、禁用安装脚本方式安装，Node 运行时页面、服务复用、权限、来源限制与原生 PTY 通过。
- 同一安装目录在桌面 Electron 运行时完成上述检查。PTY 检查改为启动 Windows 原生命令行，避免将 Electron GUI 程序当作 Node 控制台子进程。
