# v0.8.14

修复页面切换慢、日报与周报互相串页的问题，保留 0.8.13 的发布与连接流程。

- 日报、周报、内部资料按「应用 + 账号 + 根目录 + 页签」分别保存数据、同步时间和错误，切换时立即显示目标页签自己的缓存，没有缓存只显示该页签的加载占位。
- 卡片渲染再次按日报/周报类型过滤，明确属于另一类报告的卡片不会出现在当前页签。
- 进入页签先读本地缓存再后台同步，不再等待飞书目录扫描；缓存有效期 60 秒，手动刷新使用 `force=true` 强制同步。
- 同一范围的远端刷新在客户端与服务端各合并一次，连续点击或多窗口不会重复启动 CLI。
- 每个范围带请求序号，迟到的响应不覆盖较新的结果。
- 后台同步失败保留当前卡片，展示错误、上次同步时间和重试入口；失败不推进上次同步时间。
- 仅当存在运行中任务时 4 秒轮询，其余 30 秒；页面隐藏时暂停轮询。配置、公司库、分析报告不再每 4 秒重读。

新增 7 项页签缓存单测、5 项服务端同步单测和 5 项浏览器用例；原有 334 项单测与 40 项浏览器用例保持通过。飞书读取仍使用夹具，未对真实账户目录执行写入。

本次合并补充：
- 合入友商分析任务状态卡片：未发布任务也显示调研中、排队中、失败或中断状态；已发布报告仍可打开并关联任务。
- 分析接口在共享飞书同步结果后动态叠加本地任务状态，不把任务卡片写入报告索引。
- 任务状态变化时只重读本地分析卡片，兼容降频轮询与页签缓存；保留主干读取诊断和迟到响应保护。
