已存在且保持的实现包括：17家公司/5维度/默认信源、公司索引导入、资料来源和冲突标记、标准模式与完整权限、并行原生会话、30分钟超时、日报周报增量联动、原生调度及重启补发、机器人通知独立重试、友商分析及来源限制、内部资料视频音轨/ASR指令和网络断点恢复指令、平台日志。飞书绑定、重复 App ID 更新凭据和当前用户通知路径未重写。

云端导入仅能恢复飞书中可读取的文档元信息，不能恢复另一台机器的 DSH 会话，因此无本机会话记录的卡片禁用会话入口。内部资料的原始资料/会议纪要关联仍以本机已保存的交付回执为准；仅发现逐字稿时不会猜测关联文档。目录读取需可选权限，缺失不阻断调研或本地历史查看。单目录超过1000条时明确提示范围过大，避免把截断结果当作完整目录。

## 验证范围

相关单元/接口测试覆盖工作区升级、并行归组、目录设置持久化与校验、云端读取/分页/缓存/去重/目标切换、Prompt、调度、内部资料、友商分析、连接与通知回归。浏览器测试覆盖目录设置、编辑 Prompt、云端报告链接、同步错误、报告卡片、通知修复和连接入口。

独立目录验收实际离线安装 TGZ，并校验桌面 ZIP 解压后的服务与页面加载；这与用户桌面版安装和真实飞书扫码/消息验收分开记录。隔离 DSH CLI 宿主启动曾在插件状态出现前超时，不能把该项计为通过。真实飞书写入和消息不使用测试夹具冒充验收结果。
