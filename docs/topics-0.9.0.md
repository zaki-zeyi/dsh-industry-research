# 专题调研 · 0.9.0

基于飞书 PRD 修订版 325 的 FR-05。源码基线为 ff9112e（0.8.15）。

## 使用

1. 完成飞书绑定和根目录设置，进入「专题调研」。
2. 点击「启动专题调研」，填写调研问题、数据源及其他要求，可编辑任务 Prompt。自定义数据源与全量信息库共用并持久保存。
3. 启动后使用宿主原生会话调研，报告按「调研问题、调研结论、调研依据」组织，保存至根目录的「专题调研库」。卡片提供报告链接、AI 会话详情和失败重试。
4. 每张卡片可「设置日报」，默认每天 09:00（北京时间），独立修改问题、数据源、其他要求和 Prompt，保存或关闭该专题的定时任务。宿主需启用官方 Schedule 服务。
5. 日报统计前一个完整自然日的新披露，Prompt 可使用 {{时间范围}}。服务重启补跑最近一期漏发任务，同专题同一天幂等。报告完成后由绑定应用机器人通知，失败可重试通知及修复权限。

## 实现规则

- PRD 的启动 Prompt 使用「调研专题」，与存储位置名称不一致，本次统一采用存储位置明确指定的「专题调研库」。
- 同一专题一个飞书文档，日报先读取最新原文，再按事实去重增量合并；重试复用已取得链接。新专题拥有独立 ID、原生会话和定时配置。
- 复用平台保存锁及服务端目录唯一性检查；目录和文档链接随保存锁刷新，禁止 Agent 自行创建目录。
- 缓存按账号、应用、根目录和页签隔离。后台轮询只读取缓存，手动刷新或缓存过期时才同步飞书。
- 定时触发携带原账号和目录作用域，切换绑定或目录后拒绝旧定时触发。30 分钟超时、部分交付保留和原生会话重试沿用现有机制。

## 验收范围

新增 tests/topics.test.mjs 与 tests/e2e/topics.spec.mjs，覆盖输入校验、报告结构提示、目录和文档复用、完整自然日、独立定时配置、漏发补跑、幂等、目录与账号隔离、历史报告导入及页面流程。

自动验收使用隔离宿主，不发送真实通知或创建业务报告。实际模型输出质量及企业飞书权限需真实业务验收。
