# PRD1957：应用切换与平台日志

2026-11-04 获取在线 PRD revision 1957。新增平台日志与机器人重试通知边界要求。

真实诊断：登记状态完成的 App ID 是 cli_aa605ddc70b89d0f，当前绑定却为 cli_aa63e1a347389d3e。读取原账号身份的官方 CLI 返回缺少 contact:user.basic_profile:readonly；跨应用身份校验失败后业务回滚，加上界面自动恢复旧授权，掩盖了失败。

按用户最新要求移除业务自动回滚：沿用 release 的直接保存所选应用再进行个人授权的方向。账号校验失败保留所选应用和待完成状态，重新扫码可继续；不删除本机其他profile、不自动选择旧应用。保留SQLite原子写入来防止配置写到一半。

补充稳定身份读取权限。更换应用/重新绑定前，若原账号缺少身份权限，先完成原账号授权再进入新应用选择；授权途中不提前报绑定成功。

平台日志可从侧栏打开，显示登记、应用选择、账号校验失败、切换提交和通知错误。保留1000条，支持分页；只记录允许的元数据，不记录App Secret、token、device code、授权URL或资料正文。

包含工作区已有的同App ID复用profile修复：官方CLI要求app-id唯一，不通过反复新增profile修复重复App ID。

服务测试181项与浏览器测试21项通过。真实切换仍需安装新包后由用户扫码验收。本轮未在桌面安装或替换用户插件。
