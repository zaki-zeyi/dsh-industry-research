# 0.9.0 · 专题调研

- 新增「专题调研」页签，填写调研问题、数据源、其他要求及可编辑 Prompt，使用 DSH 原生会话开展研究。
- 报告以调研问题、调研结论、调研依据组织，保存至飞书根目录的「专题调研库」，支持历史报告刷新、原生会话续聊及失败重试。
- 每个专题独立设置北京时间日报，默认 09:00；复用官方 Schedule 服务，支持最近一期漏发补跑、按专题和日期去重触发及机器人通知重试。
- 同一专题复用原文档并去重增量合并；沿用保存锁、目录唯一性检查、30 分钟超时、账号/应用/根目录隔离和页签缓存。

验收：本机 369 项业务测试通过、2 项按平台条件跳过，47 项浏览器验收通过；Mac 与 Windows 的 GitHub 自动验收通过，桌面 ZIP 独立安装及 Node/Electron 加载验证通过。真实模型输出质量和企业飞书权限仍需真实业务验收。
