# v0.13.2

修复原生 AI 会话失败后保存锁残留、重试无法写入全量信息库的问题。Key 失效、额度不足或网络异常导致宿主轮次报错时，平台撤销旧保存许可；没有在途写入时自动释放，有写命令或目录准备尚未结束时等待确认后交锁。增加空闲许可超时回收和写命令结束回报丢失补偿，重试必须重新取得许可，旧轮次及迟到回报不能影响新锁。

保留 Agent 负责内容合并和飞书写入的方式，平台在提交阶段及每条写命令启动前校验权限。保存完成后同步任务详情、执行历史和卡片状态。

验证包括真实桌面 DSH 安装、真实飞书写入，以及在隔离真实 DSH 宿主中拿锁后由模型接口返回 401、402 或直接断连的三类故障；故障轮次没有 Agent 失败回执，重试后公司文档和索引均写入并读回，详情及历史卡片恢复完成。详见 [模型接口异常补测记录](model-transport-failure-acceptance-0.13.2-dev.3.md)。

安装提供包含前端构建和生产依赖的桌面 ZIP、TGZ 及 SHA256 校验文件。已有运行中的旧会话需要确认结束后从工作台重试，以创建使用新保存许可协议的执行绑定；无法确认结束的在途写入继续保留阻断，不通过强制清锁绕过并发保护。
