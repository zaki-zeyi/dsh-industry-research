# 0.11.0 · 删除专题

- 对齐 PRD revision 519：专题卡片增加删除按钮，先核对并展示专题名称、总报及日报数量，再由用户确认。
- 按用户确认的范围，先停止该专题的宿主日报任务，再将专题目录及其中全部内容移入飞书回收站；旧版平铺专题只删除确认的文档，不删除共享父目录。
- 删除入口与整卡进入专题相互独立。取消不会删除；正在调研、保存或通知的专题提示先完成或停止任务。
- 校验当前账号、根目录与确认后的目标，内容变化须重新确认。删除未确认完成时保留卡片；异步任务 ID 持久化，重启和重试可继续核对。
- 删除权限作为可选能力，已有授权可直接使用；缺少删除权限时先引导补充授权，不停止日报，不影响原有调研和绑定。
- 删除完成后刷新不会恢复旧卡片；旧任务、定时触发和迟到交付不能重新创建已删专题。重新创建同名专题会重新发现有效目录。
- 回收站操作在用户点击“确认删除”后执行，验收使用隔离测试数据，不删除真实调研。

验证涵盖取消、完成与异步删除、宿主停止失败、权限/网络异常、目标范围变化、运行中任务保护、缓存竞态及同名目录重建。
