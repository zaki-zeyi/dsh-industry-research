# 专题总报与日报 · 0.10.0

依据飞书《行研平台 PRD》修订版 468。用户已确认将文中“专题调研”和“专题调研库”两种新目录名称统一为“专题调研”。

## 页面与存储

- 专题列表：展示各专题卡片，点击标题或“进入专题”进入详情页。
- 专题详情：分别展示“专题总报”和全部“专题日报”，可打开飞书文档、进入对应 AI 会话续聊、重试失败任务或失败通知。
- 启动专题调研：填写“调研方向”、数据源、其他要求及可编辑 Prompt。数据源继续复用全量信息库组件。
- 总报：保存在根目录 / 专题调研 / 具体专题 / 总报。
- 日报：保存在根目录 / 专题调研 / 具体专题 / 日报，每期一个文档，保留历史日期的全部卡片；同一期重试复用原链接，不覆盖总报或其他日期日报。
- 在专题详情页“设置日报”，按北京时间独立配置时间及研究范围。默认每天 09:00，沿用官方 Schedule、最近一期补发、触发幂等和通知重试机制。

## 兼容与保护

- 旧版“专题调研库”平铺报告仍可读取并作为总报展示，不在刷新时移动或修改远端文档。
- 旧版日报曾更新同一个总报，其历史记录继续归入总报。升级后的新日报独立保存。
- 重新开展旧专题的总报调研时，复用旧文档链接，由 Agent 在保存锁内按官方 Drive 操作移到对应专题目录，不删除或重复创建旧报告。
- 服务端在保存锁内复用专题及日报目录，并发现已有“总报”；交付回执验证实际目录及报告类型，不允许跨专题或跨日期覆盖。
- 列表、详情及刷新按账号、应用、根目录隔离；从 AI 会话返回保留当前专题，切换目录或账号不展示旧范围的数据。

## 验收范围

新增或更新业务与浏览器验收，覆盖层级目录发现、总报与两期日报独立保存、分期去重和排序、旧版链接兼容、目录复用、详情页刷新、返回列表和原生会话续聊。

自动验收使用隔离宿主和模拟飞书响应。真实模型输出及企业飞书权限仍需业务使用时核验。
