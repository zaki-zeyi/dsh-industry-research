# DSH 行研工作台 0.8.4

发布日期：2026-11-05

## 飞书绑定恢复

- 云盘目录列表权限 `space:document:retrieve` 改为首次发现公司索引时使用，不再作为扫码绑定、调研和已有索引刷新的硬门槛。
- 已保存公司索引时，「保存设置并导入」直接读取索引，不再调用云盘目录列表接口，避免应用未开通目录列表权限时导入失败。
- 修复设置飞书根目录链接后本地公司库索引键变化的问题。公司档案和友商分析报告不会因为补充根目录链接而显示为 0。
- 扫码等待期间，Lark CLI 若提前返回 `authorization_pending`，工作台会自动续查直到二维码过期，不再提前终止个人授权。
- 修复扫码成功后界面停留在“正在校验账号并提交绑定”的问题：个人 token 的授权时间晚于待提交应用切换时，状态接口会自动补提交，无需再次扫码；旧 token 不会被用来误确认新应用。
- 保留 DPoP 密钥不可用时的 Bearer 兼容修复入口；该入口不会修改 Codex 或其他飞书 profile。

## 回归覆盖

- 新增“缺少目录列表权限仍可绑定和调研”测试。
- 新增“已有公司索引直接导入、不调用目录列表”测试。
- 新增“根目录链接变化不影响公司库索引”测试。
- 新增“扫码 pending 自动续查”测试。
- 新增“扫码成功后自动补提交待绑定应用”测试，并保留“旧 token 不得提前确认新应用”的安全回归。
- 飞书绑定、导入、授权恢复、公司库和友商分析相关测试全部通过。
