# DSH 行研工作台 0.8.5

发布日期：2026-11-06

合并 `02_Daily/Weekly_Report` 的 0.6.13 改动至 `merge02-04`，保留友商分析、根目录导入与安装器源码。

- 飞书连接使用已验证的简化 release 连接基线，合入已有 profile 凭据更新、Windows 原生 CLI 定位和相对路径二维码修复。没有重新引入旧的自动账号切换事务或 Bearer 自动恢复界面。
- 平台日志统一放在右上角，“飞书连接监测”为子栏目，支持 traceId 链路筛选、耗时和脱敏错误诊断。
- 历史任务点击“重试通知”后，通过当前绑定应用向当前已验证用户发送；成功后显示绑定变化提醒，失败不显示“已发送”。
- 按发送目标隔离幂等键，保留历史报告文档与研究应用快照。
- 保留友商分析、首次导入和公司索引功能；目录列表权限仍仅用于首次导入，不作为日常绑定与调研的硬门槛。

## 发布验证

选定的 72 项相关测试通过，覆盖友商分析、日志链路、凭据更新、二维码、通知迁移及安装器静态约束。旧认证事务相关测试保留作历史参考，不代表本版本承诺支持旧自动恢复流程；没有宣称整套历史测试全部通过。

发布附件提供插件桌面 ZIP 和 npm TGZ，以及对应 SHA256 文件。该发布不提供新的整合式 Windows EXE 安装器；ZIP 可解压后在 DSH 插件管理中安装。没有安装或更改用户正在运行的 DSH，也没有发送真实飞书消息。
