# dsh-industry-research · 行研工作台

基于飞书《行研平台prd轻量化》修订版 1917 实现的 DeepSeek Harness 插件，并合并 PRD449「FR-03 友商分析」。复用本机既有调研工作台的宿主适配与授权代码，在独立命名空间内提供公司全量信息库、日报/周报、内部资料与友商分析。

- 默认 17 家公司、5 个维度、16 个信源，支持全网查询与自定义；新增维度和信源持久保存。
- 编辑任务 Prompt，绑定飞书后启动 DSH 标准模式原生会话；所有任务共享插件工作区。
- “重新绑定”要求登录另一个飞书账号，并选择或创建该账号可管理的应用；“更换应用”保持当前账号不变。目录缓存按应用和个人账号隔离。
- 工作台保留“绑定飞书”“更换应用”“重新绑定”三个独立入口，分别用于当前绑定、同账号换应用和换账号重绑，并各自生成二维码。
- 飞书根目录下建立「全量信息库」，一家公司一份文档。向 Agent 提供已有文档链接，要求先读后增量更新、去重，逐条引用来源和日期，保留并标注冲突。
- 单次调研超过 30 分钟仍未完成则失败，保留已完成文档和会话记录。
- 历史 AI 任务位于全量信息库页面内的页签，和公司文档卡片分开展示，支持搜索、继续对话、失败重试；部分完成时保留已交付公司。
- 已知「公司索引」飞书文档支持刷新公司清单。设置飞书根目录后，点击「保存设置并导入」会只读读取该目录一次，优先从「全量信息库/公司索引」导入，没有索引时按公司文档名称识别；不枚举无关目录。SQLite 只镜像文档链接、维度和交付统计等元信息。
- 独立「友商分析」页签支持选择至少两家已收录公司和对比维度，默认 Prompt 可编辑；报告严格只引用全量信息库，资料不足时明确标注。
- 友商报告保存在飞书根目录的「友商分析」子目录，通过「分析报告索引」刷新历史卡片；每张卡片可打开报告或回到对应 AI 会话。

## 日报与周报（FR-02）

独立日报/周报页签显示报告卡片、飞书链接和原生 AI 会话。支持手动配置公司、维度、信源、其他要求及编辑 Prompt；日报统计前一个完整自然日，周报统计前七个完整自然日（北京时间发送日前第七天 00:00 至发送日 00:00，左闭右开），统一北京时间。按披露日归档，保留事件发生日和入库日，缺口与待核对日期不能当作无更新。

按 PRD512，生成报告同时去重增量更新全量信息库，复用公司原文档与索引；无更新公司不写入。完成后原生会话显示报告链接、更新摘要或“本日/周无更新”；工作台以任务绑定应用的机器人身份通知任务启动时绑定的用户。通知失败不影响报告保存，可单独重试，使用同一消息幂等键避免重复通知；账号/应用切换后停止发送。机器人须开通 `im:message:send_as_bot`，且绑定用户必须在机器人可用范围内。

通知失败时工作台会保留安全的飞书错误码和缺失 scope，并提供“修复机器人权限”入口。该入口只更新当前应用权限；修复应用并发布后可对原报告重试通知，不会重新调研或重复创建报告。

PRD1814 要求 DSH 在定时发送时间关闭时，服务重启后补发最近一次错过的日报或周报，并补发对应的飞书机器人消息。补发按周期幂等，已有任务不重复创建；服务正常运行但用户修改配置时，已经过去的发送时间不会意外补跑。

日报/周报页签分别提供「手动生成」和「定时生成」入口。定时弹窗与手动任务共用公司、维度、信源、自定义配置及可编辑 Prompt；分别保存，互不覆盖。默认日报每天 09:00、周报每周五 09:00，可修改并启用。自定义 Prompt 中的 {{时间范围}} 在执行时替换。通过官方 DSH Schedule 服务持久化定时任务；到点由宿主唤醒调度会话，为每期创建独立报告会话。同一天同类定时触发幂等。宿主需运行并配置可用模型与飞书授权。插件不依赖第三方自动化插件。

## 多会话并行（PRD815）

启动任务后即可并行调研，无全局单任务阻塞。各任务拥有独立原生会话、Prompt 和交付回执；仍以同一插件工作区作为会话分组。

保存同一飞书信息库前，Agent 运行插件提供的保存锁客户端；成功取得锁后使用返回的最新目录、公司链接和索引，读取远端原文后增量合并。检索阶段并行，保存阶段互斥；等待时显示「等待保存」。取消、失败或结束会释放锁。目录创建结果不确定时仍停止重建，要求核对已有链接。已有运行会话的历史指令不追溯修改，新任务和重试使用新协议。

## 内部资料（PRD1814 · FR-04）

通过 DSH 桌面宿主的文件选择器确认原始完整路径并在表单中完整显示，或填写网络链接。平台只保存路径元信息，不复制文件、不传输文件内容；已移除二进制导入接口。网页版没有桌面路径桥接时提示使用桌面版或网络链接。沿用已保存目录配置，弹窗不提供目录编辑项。默认目录结构为“内部资料 / 原始资料、逐字稿、会议纪要”。视频提取音轨，按时间、说话人、话语生成逐字稿并校对 ASR 错误；纪要附逐字稿与原始资料链接。单份本地原始文件上传上限为 100 MB。网络失败由原生 Agent 按 CLI 能力恢复上传，不能续传时重新上传并核对成功回执。

卡片显示本地原始文件名或 Agent 读取到的网络资料标题，长标题最多显示两行并可通过悬停查看全文。提及已配置公司时，Agent 去重增量更新全量信息库原文档与公司索引。服务校验目录、文档链接和公司归属；逐字稿、会议纪要及同步回执完整后才标记完成。部分结果保留供原会话重试，历史卡片分别打开逐字稿、纪要、原始资料和 AI 会话。历史旧版记录保持可见。完成后向绑定用户发送结果链接。

## 本地开发

需要 Node.js ≥22.13。

```bash
npm ci
npm run dev
```

开发界面访问终端显示的 Vite 地址。默认运行离线流程演示，不检索真实资料或写入飞书；演示任务只验证表单和任务流。真实调研必须在 DSH 插件宿主中执行，使用宿主已配置的模型和工具。

```bash
npm run acceptance
npm run test:native-host
npm run plugin:pack
```

`acceptance` 包含构建、业务/API 回归与浏览器验收。`test:native-host` 启动隔离的真实 DSH 宿主，模型和飞书交付使用本机测试夹具，不调用外部模型或修改真实飞书文档。

## 安装

Windows 10/11 x64 用户优先使用一键安装包：

- `artifacts/DSH-Industry-Research-Windows-Setup-v0.8.2-x64.exe`

安装器会在开始前检查系统：仅允许 Windows 10/11 x64。32 位 Windows 10 和 Windows 11 ARM64 会被明确阻止；官方 DeepSeek Harness 桌面端目前没有 32 位构建，不能只靠修改安装脚本增加 x86 支持。

从 `v0.8.2` 起，安装器采用标准 Windows 安装规范：重复双击只会保留一个安装窗口，安装与卸载不能并发；安装完成后会出现在“设置 > 应用 > 已安装的应用”，并生成标准 `Uninstall.exe`。支持 `/S` 静默安装和静默卸载，失败时返回非零退出码。

安装器会先安装官方 DeepSeek Harness（未安装时），再预装并启用行研工作台和 3 个精选插件，无需 Node.js、npm 或手动添加插件：

- 商标 Branding `dsh-brand@0.2.0-rc.6`
- 插件市场 `dshmarket@1.73.11`
- IM 机器人 `@xmanrui/dsh-im@5.10.0`（飞书、微信、企业微信、钉钉、QQ、Slack、Telegram、Discord 等）

安装包内附未修改的官方 DeepSeek Harness `0.2.0-rc.2` 安装器；已有 DSH 设置、账号和调研数据会保留。如果已有同名插件，安装器会保留用户当前的插件来源，不覆盖其配置。悬浮球项目是独立的 DeepSeek Orb 桌面应用，不是 DSH 插件，因此不在一键安装包的插件列表中。

运行 `npm run plugin:pack` 后生成：

- `artifacts/dsh-industry-research-0.8.2-desktop.zip`
- `artifacts/dsh-industry-research-0.8.2.tgz`
- `artifacts/dsh-industry-research-0.8.2/` 可直接安装目录

维护者可依次运行 `npm run plugin:pack`、`npm run bundle:plugins`、`npm run bundle:windows` 重新生成 Windows 一键安装包。`bundle:plugins` 会下载 `installer/windows/bundled-plugins.json` 中固定版本的插件包并校验 SHA256。需要本机已有官方 DSH 安装器、NSIS，并可通过 `DSH_DESKTOP_INSTALLER` 和 `MAKENSIS` 覆盖默认路径。

在 DSH 桌面版「添加插件」中填写上述解压目录的绝对路径，按宿主提示启用或重新加载。Windows 和 macOS 使用同一个 ZIP；网页版可以使用 DSH CLI 安装 tgz。详见 [安装说明](docs/plugin-install.md)。

公开仓库：[zaki-zeyi/dsh-industry-research](https://github.com/zaki-zeyi/dsh-industry-research)。

在 DSH「添加插件」中填写仓库地址即可安装。默认 `release` 分支包含预构建页面和完整生产依赖，无需执行安装脚本；开发源码位于 `main` 分支。

```text
https://github.com/zaki-zeyi/dsh-industry-research
```

## 验证边界

自动测试验证配置持久化、宿主会话、交付回执、公司/友商报告索引、错误恢复与界面交互。真实扫码授权、企业审批、付费信源可访问性和实际调研内容质量需要真实环境验收。Agent 声称完成时须交付公司或友商报告的真实飞书链接；平台校验回执结构、来源范围及链接稳定性，不逐条审计远端事实。增量去重、图表和文档内高亮由 Agent 执行。
